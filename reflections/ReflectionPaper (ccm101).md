Cloud computing has become a normal part of my daily life because I use different online services for school, communication, and personal tasks. Three cloud applications that I use almost every day are Google Drive, Facebook Messenger, and Canva. These services allow me to access my files, communicate with classmates, and create presentations from any device with an internet connection. They make my work more convenient because I do not need to carry files on a flash drive or install large programs on my computer. I can also continue my work from my phone or another computer, making it easier to stay productive wherever I am.

Google Drive is an example of **Software as a Service (SaaS)** because it provides online file storage and document editing without requiring users to manage the hardware or software. It uses the **Public Cloud** deployment model since it is available to anyone with a Google account. Facebook Messenger is also a **SaaS** application because it offers messaging, voice calls, and video calls through the internet. It is classified under the **Public Cloud** because it serves millions of users worldwide. Canva is another **SaaS** platform because it allows users to create graphic designs and presentations directly through a web browser. It also uses the **Public Cloud** since anyone can access its services by creating an account. These cloud services help me complete assignments, communicate with classmates, and share files quickly and efficiently.

Version control is essential in cloud computing because it keeps a complete history of changes made to files and configurations. If mistakes happen, previous versions can easily be restored without losing important work. GitHub makes collaboration more organized by allowing multiple team members to work on the same project at the same time using branches and pull requests. It also tracks every change, making it easy to identify who made specific updates and when they were made. Overall, learning Git and GitHub has helped me understand how cloud projects are managed efficiently, reducing errors while improving teamwork, productivity, and project organization. I believe these skills will be valuable in my future career as an IT professional because they encourage collaboration, responsibility, and better project management.
