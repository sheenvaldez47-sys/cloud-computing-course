# Cloud Computing Reflection

Cloud computing has become an important part of my daily life because I use many online applications for communication, learning, and storing files. Three cloud services I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because it allows users to store, edit, and share files through a web browser without installing complex software. It uses the Public Cloud deployment model because its services are available to anyone with a Google account through the internet.

Facebook Messenger is also a SaaS application because it provides online messaging, voice calls, and video calls through the cloud. Like Google Drive, it operates on the Public Cloud since millions of users can access it online.

Canva is another SaaS application because it allows users to create presentations, posters, and graphics directly from a web browser. Canva also uses the Public Cloud because it is available to users worldwide through the internet.

Version control is very important when working on cloud infrastructure because it records every change made to files and configurations. If mistakes happen, previous versions can easily be restored. It also helps developers understand who made specific changes and when they were made.

Git and GitHub make teamwork easier by allowing multiple people to work on the same project without overwriting each other's work. Developers can create branches, review changes, and merge updates safely. GitHub also keeps a complete history of every modification, making collaboration more organized and reducing errors. Learning Git and GitHub is an essential skill for managing cloud computing projects because it supports teamwork, improves productivity, and ensures that important project files remain secure and well organized.
